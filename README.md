# Job Prediction Service - Phase 2

**Job Prediction Service Phase 2** -  After cleaning, processing data and Exploratory data analysis being performed in phase 1, here more significant algorithms from Machine Learning (ML), statistical modeling, and/or MapReduce (MR) are applied to start gaining intelligence from data.

**Algorithms Applied:**
  1. Linear Regression
  2. Random Forest
  3. Logistic Regression
  4. KNN
  5. Support Vector Regression (SVM)
  6. Gradient Boosting
